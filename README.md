## Project Overview

This project analyzes bike buyer data to understand customer characteristics and purchasing patterns using Microsoft Excel.

The analysis includes data preparation, Pivot Table analysis, and dashboard development. The final dashboard brings key findings together in a clear and interactive format.

---

## Analysis

The dashboard examines bike purchase behavior across different customer characteristics, including:

* Customer demographics
* Age groups
* Income
* Commute distance
* Bike purchase patterns

The analysis uses Excel-based summaries and visualizations to identify patterns in customer purchasing behavior.
